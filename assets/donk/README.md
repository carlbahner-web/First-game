# Donk sprite pieces

Upload the four PNGs from BUZZ's Wild Ride (`games/src/assets/`) here,
with these exact names:

- `donk-body.png`   (819 x 560 — charcoal shell + face)
- `donk-button.png` (819 x 560 — cream drumhead; same crop as the body, load-bearing)
- `donk-arm.png`    (331 x 404 — one arm, far side mirrored in code)
- `donk-leg.png`    (270 x 509 — one leg + shoe, ditto)

The game loads them automatically; until they exist the procedural
goblins draw as the fallback.
