# Reference docs from BUZZ's Coaster Run

Not written for this game. These are the coaster's own design write-ups, which
Carl supplied as the source material for StudioLand's look — they are where the
palette, the HUD's grammar and the start screen's anatomy come from.

They are kept here because they were the thing being built against all through
this game's visual overhaul, and without them a lot of decisions in `game.js`
look arbitrary. Alert red being deadly-only comes from `palette-and-style.md`.
The HUD having no panels comes from `hud.md`. The title card's whole lineage is
in `start-billboard.md`.

Read them as the coaster's answers, not as this game's rules. `../design.md` is
where those answers were generalised, and it records where this game chose
differently.
